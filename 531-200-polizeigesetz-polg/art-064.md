# § 64 Änderung bisherigen Rechts
1 Das Gesetz über die Einwohnergemeinden (Gemeindegesetz) vom 19. Dezember 1978 wird wie folgt geändert:
Text im betreffenden Erlass eingefügt.
2 Das Gesetz über die Strafrechtspflege (Strafprozessordnung, StPO) vom 11. November 1958 wird wie folgt geändert:
Text im betreffenden Erlass eingefügt.
3 Das Einführungsgesetz zum Ausländerrecht (EGAR) vom 14. Januar 1997 wird wie folgt geändert:
Text im betreffenden Erlass eingefügt.
